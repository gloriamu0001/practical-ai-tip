## 83. Keep What Varies in a Settings File the Skill Reads

Keep a skill the same everywhere, and keep the facts that differ per person or project in a small file the skill reads on each run. On first use, the skill asks for the facts and saves them.

- **Use when:** a skill needs personal or project facts, such as a channel name or a sample of the desired output.
- **Implementation:**
  1. Put the facts that vary in a separate file.
  2. Have the skill read that file every time it runs.
  3. If the file is missing, have the skill ask the user for the values and write them to the file.
  4. Keep the skill's own text identical across projects.
- **Asset:** the source's first-run pattern (it uses a small shell command): [post on authoring skills](https://x.com/trq212/status/2033949937936085378).
- **Limits:** data inside a skill's own folder may be deleted on upgrade; not for preferences such as tone.
- **Requires:** an agent that supports skills and can write files.
