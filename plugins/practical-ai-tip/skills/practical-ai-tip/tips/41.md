## 41. Use the Cheapest Check That Works

Fix obvious gaps in the instructions first, use simple rule-based checks where a rule can decide, and keep costly AI-judged checks for failures that persist and matter.

- **Use when:** deciding how to check an AI workflow's output.
- **Implementation:**
  1. Fix obvious gaps first, such as a preferred format or length that was never stated.
  2. Where a simple rule can catch an error, use it, for example a check that the output is in the expected format.
  3. Use an AI judge only for judgement calls, and only for problems worth checking repeatedly.
  4. Write checks for errors seen in real outputs, not for imagined errors, and not as ready-made generic quality scores.
  5. Run cheap checks often. Run costly ones less often, and retire or toughen a check that always passes.
- **Limits:** an AI judge needs labelled examples and upkeep.
