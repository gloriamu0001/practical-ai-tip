## 87. Build a Knowledge Base the AI Writes and Maintains

Collect source documents in one folder, and let the AI turn them into a linked set of notes that it maintains. At small scale, the AI answers questions from it without a retrieval system.

- **Use when:** building up knowledge on a research topic, a client, or a field over time.
- **Implementation:**
  1. Save source documents (articles, papers, images) into a `raw/` folder. A web clipper can turn web pages into text files.
  2. Ask the AI to build a wiki from them: summaries, concept pages, links between pages, and index files. The AI writes and maintains it; people rarely edit it by hand.
  3. Ask questions against the wiki. Have the answers produced as files (notes, slides, charts), and file the useful ones back into the wiki, so every question adds to it.
  4. Run regular checks: ask the AI to find inconsistent data, fill gaps, suggest new pages, and check notes against the original sources.
  5. Keep the raw sources unchanged: the AI reads them but never edits them. Write a rules file that says how the notes are structured and how to add a source.
  6. Add sources one at a time, read the AI's summaries, and guide what to emphasise.
  7. Keep an index file that the AI reads first, and a log of what was added and checked, with entries in one consistent format.
- **Asset:** the source's idea file, written for an agent to build from: [LLM wiki gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).
- **Limits:** beyond about 100 articles and 400,000 words, search tools may be needed; notes can be wrong or drift.
- **Requires:** an agent that reads and writes files; a note app such as Obsidian to view the wiki.
