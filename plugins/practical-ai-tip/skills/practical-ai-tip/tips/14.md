## 14. Record Hard Decisions as They Settle

During planning, write each decision that is hard to undo into a file the moment it is settled, so later sessions and other people do not have to argue it again.

- **Use when:** planning a project that will run over many sessions or involve other people.
- **Implementation:**
  1. Write a short decision record (a file that states one decision and the reason for it) as soon as the decision settles.
  2. Write a record only for a decision that is hard to reverse, surprising without context, and a real trade-off. All three must hold.
  3. Carry all other decisions in a handoff document. Most decisions do not need a record.
