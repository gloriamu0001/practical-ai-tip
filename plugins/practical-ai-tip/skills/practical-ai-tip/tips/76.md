## 76. Start With One Agent Plus Skills; Add Helper Agents Only for a Reason

A single agent with skills often matches or beats a set of specialist agents on quality, cost and speed. Split work across agents only when a clear condition applies.

- **Use when:** designing an agent setup, or considering adding helper agents.
- **Implementation:**
  1. Start with one agent, and put specialist instructions into skills.
  2. Add a helper agent only when:
     - one agent shows a measurable decline from too much in its context
     - several tasks can run in parallel with fresh context windows
     - one agent struggles to choose among its tools, or its instructions conflict
  3. Do not give each team or each type of problem its own agent.
  4. Compare results with and without the helper agent before keeping it.
- **Limits:** each helper agent costs tokens.
- **Requires:** an agent that supports skills.
