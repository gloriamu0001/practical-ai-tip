## 33. Audit the AI Setup Regularly

Unused skills, tools, connectors and bloated instruction files add to every request without being noticed, and old connections keep access to data. Measure, remove what is not used, and measure again.

- **Use when:** requests feel slow or costly, or the setup has grown over months.
- **Implementation:**
  1. Measure what each request carries: `/context` in Claude Code shows the tokens per category.
  2. Run `/doctor` (also called `/checkup`) in Claude Code. It reports its findings and changes nothing until the user confirms; review every deletion before confirming. It compares unused skills, connectors and plugins with their cost in the context window, flags slow hooks, and offers to move always-loaded instructions into files that load only when needed.
  3. To audit the instruction files and skills instead, run `/doctor prompt-audit`. It flags instructions written for older models, pointers to files that no longer exist, and instructions that contradict each other.
  4. Turn off whole features that are not used. In Claude Code, add a bare tool name under `"permissions": {"deny": [...]}` in `~/.claude/settings.json` to remove a tool. A scoped rule only blocks the call and leaves the tool's description in every request.
  5. Remove old connectors, integrations and access keys that are no longer needed: they keep access to data.
  6. Restart and measure again.
  7. Keep each rule in exactly one place. When rules overlap or conflict, the AI ignores one of them; current models also do not need repetition or reminders at the end.
- **Asset:** a prompt that cleans up a bloated instruction file: finds contradictions, keeps the essentials, splits the rest into files, and flags deletions. [Full prompt](https://www.aihero.dev/a-complete-guide-to-agents-md#fix-a-broken-agentsmd-with-this-prompt).
- **Limits:** some tools that look unused serve background jobs and multi-agent runs.
- **Requires:** Claude Code, for the commands.
