## 50. Put a Short Human-Chosen Opener First

When AI writes a long, accurate description for a reader, start with a short opener that a person has chosen as worth the reader's time.

- **Use when:** sharing an AI-written report, description or summary with others.
- **Implementation:**
  1. Write the opener as the shortest text that tells the reader what the work is for and whether it deserves attention. The AI may draft it, but it must reflect a person's judgement of what matters.
  2. Add a screenshot where one shows the point fastest.
     > [!info] Sources disagree
     > For the full AI-written text, one source folds it below the opener[^SW-opener]; another stops using AI-written descriptions altogether[^KV-desc].
