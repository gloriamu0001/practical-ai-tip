## 74. Carry Progress Between Sessions in a File

When work spans several sessions, a short progress file saves each new session from rediscovering what was already done.

- **Use when:** an agent works through a task list over several sessions.
- **Implementation:**
  1. Ask the agent to append a short entry after each task, using the prompt below.
  2. Start each new session with the task list and the progress file.
  3. Delete the file when the batch of work ends; it is not permanent documentation.
  4. Keep a small file with the current goal and the next steps, rewritten as the work proceeds.
- **Asset:** the source's prompt:
  ```
  After completing each task, append to progress.txt:
  - Task completed and PRD item reference
  - Key decisions made and reasoning
  - Files changed
  - Any blockers or notes for next iteration
  Keep entries concise. Sacrifice grammar for the sake of concision. This file helps future iterations skip exploration.
  ```
  ("PRD item" means the task's entry in the requirements list.)
- **Limits:** the file grows with each task.
- **Requires:** an agent that reads and writes files.
- **Reference:** [^M-ralph11][^AMEM]
