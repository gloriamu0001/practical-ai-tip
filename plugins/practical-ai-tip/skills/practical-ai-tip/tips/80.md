## 80. Build a Skill by Doing the Task Once First

Do the task once in a normal session, then have the AI turn what was done into a skill, and improve the skill from real corrections.

- **Use when:** a task is worth repeating but its steps are not yet written down.
- **Implementation:**
  1. Do the task once, interactively, in a normal session.
  2. Ask the AI to turn what was just done into a skill.
  3. Run the skill on the same or a similar task.
  4. Correct the output in the same session, so the corrections are part of the conversation record.
  5. Ask the AI to update the skill from those corrections.
  6. When the skill's result can be checked automatically, have an agent run it on several test inputs, check each result and its token cost, edit the skill and repeat. Set the stop rule in advance: stop when the edits become minor.
- **Limits:** the first version rarely works perfectly; automatic tuning can settle short of the best and costs tokens each round.
- **Requires:** an agent that supports skills; for automatic tuning, an agent that can start other agents.
