## 88. Prefer Memory That Can Be Seen and Edited

Automatic memory carries corrections forward, but it can over-weight old topics. Keep the important knowledge in memory that can be inspected and edited.

- **Use when:** setting up memory for an agent, or when answers keep bringing up stale details.
- **Implementation:**
  1. Use automatic memory in Claude Code (`/memory`), and switch on its periodic clean-up, which removes stale and duplicate notes.
  2. Review what the memory holds from time to time, and delete what no longer applies.
  3. To fill memory, have the AI interview the user and save the answers. To refresh it, have the AI interview the user about what may be out of date.
  4. Keep important personal or project knowledge as plain files the user owns, for example a wiki. These are explicit, inspectable, and usable with any AI tool.
  5. Store facts separately from preferences and working rules.
  6. Tell the AI what its memory is for, rather than giving fixed rules about what to record.
- **Asset:** the source's two prompts, to fill memory and to refresh it:
  ```
  Interview me in depth using free text, or askuserquestion tool when multiple choice works, about relevant parts of my life you don't know about yet and save it all to memory.
  Interview me about anything in memory that might have gone out of date and update it.
  ```
- **Limits:** current models tend to over-use retrieved memory; carried-over memory can hold wrong or planted content.
- **Requires:** an agent with memory features or file access.
