## 8. Skip a Separate Planning Mode; Align Through Conversation

Current models do not need a separate planning step. A built-in plan mode tends to ask too few questions and produce a long plan nobody reads. Reach shared understanding through conversation instead.

- **Use when:** starting any task that is not completely clear.
- **Implementation:**
  1. Start in the normal working mode.
  2. Before any work, have the AI ask questions until both sides agree on the goal, for example:
     ```
     Interview me relentlessly about every aspect of this until
     we reach a shared understanding.
     ```
  3. Once agreed, have the AI write the plan to a file, then build from that file in a fresh session.
- **Limits:** a separate written plan still helps as a record of intent or for decisions likely to change.
