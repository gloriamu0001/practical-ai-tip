## 39. Keep Side Work Out of the Main Conversation

Detours and side questions clutter the main conversation. Send them elsewhere, and use helper agents only for the jobs they are good at.

- **Use when:** a side question comes up during work, a different direction is worth trying, or a sub-task would flood the conversation with output.
- **Implementation:**
  1. **Side question:** type `/btw` plus the question. The answer uses the full conversation but is not added to it.
  2. **Different direction:** branch the conversation with `/branch`, so the original stays intact.
  3. **Helper agents** (subagents: agents with their own context window that return a short result) are worth it for three jobs: work that can run in parallel, long output that will not be needed again, and a review by an agent that has not seen the work.
  4. Keep a procedure in the main conversation, as a skill, when each step should stay visible.
- **Limits:** no better answer to the same task; costs extra tokens and can be slower; reviewers on weaker models can miss faults.
