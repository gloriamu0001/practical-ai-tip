## 65. Reduce Permission Interruptions Safely

Approving every action by hand interrupts the work, but switching all checks off is unsafe. Let the tool approve safe actions and flag risky ones.

- **Use when:** permission prompts interrupt agent work often.
- **Implementation:**
  1. Turn on auto mode in Claude Code. An automatic safety check approves safe actions and still flags risky ones.
  2. Pre-approve known safe actions with `/permissions`, and share the list with the team.
  3. Without auto mode, run `/fewer-permission-prompts`. It scans past sessions for repeated safe actions and suggests adding them to the allow list.
  4. Run the agent in a sandbox (`/sandbox`): a walled-off environment that limits which files and network addresses the agent can reach.
  5. Keep the list of automatically approved actions short, and review it.
  6. Put anything that must never happen in a deny rule.
- **Limits:** the automatic check can be wrong; approving by hand wears out attention.
- **Requires:** Claude Code; auto mode: not available on every plan.
