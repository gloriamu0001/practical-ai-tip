## 28. Keep Always-Loaded Instructions to the Essentials

An instruction file that loads into every session (such as CLAUDE.md) costs attention in every session. Keep only what the AI cannot discover and what every task needs.

- **Use when:** writing or reviewing a standing instruction file, custom instructions or project instructions.
- **Implementation:**
  1. Test each line: is it impossible for the AI to discover on its own, and relevant to every task? If not, remove it, or move it into a separate file or skill that loads only when a task needs it.
  2. Keep the purpose of the project and its known pitfalls.
  3. Never auto-generate the file. Generated files list things the AI can find itself and go stale fast.
  4. Give the file an owner, and review changes to it.
  5. Write it as a short overview that points to other files.
- **Limits:** the more instructions in one place, the less strictly each is followed.
- **Requires:** an AI tool with standing instructions and file access.
