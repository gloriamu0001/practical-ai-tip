## 34. Revisit Saved Instructions After a Model Change

Skills and memory written for an older model often contain corrections that model needed; carried forward, they can hold a newer model back.

- **Use when:** a new model becomes the default.
- **Implementation:**
  1. Ask the AI to review the saved skills and memory against the new model.
  2. Keep what still fits; rewrite or remove what was written for the older model, including long lists of things not to do.
  3. Retest important tasks with the new model. For a skill packaged as a plugin (a bundle of skills and settings that installs in one step), the terminal command `claude plugin eval init` in Claude Code sets up test cases and checks; each case also runs without the plugin, to show what the plugin adds.
  4. If the new model works badly with the existing skills, try it without them, and rebuild the workflow around the new model.
- **Asset:** the source's prompt:
  ```
  Go through my skills and saved memory. Which still fit, and which were written for an older model?
  ```
- **Limits:** every evaluation run counts against the plan's usage.
- **Requires:** skills or memory files.
