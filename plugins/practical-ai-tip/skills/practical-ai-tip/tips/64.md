## 64. Enforce Must-Hold Rules With Permissions or Hooks

An instruction such as "never do X" makes a mistake less likely but does not prevent it. For rules that must always hold, use a mechanism the AI cannot ignore.

- **Use when:** an action must never happen (deleting, sending, publishing), or must always happen.
- **Implementation:**
  1. Block or allow actions with permission rules.
  2. For checks that need logic, use a hook: a script that runs at a fixed point in the agent's work. A hook that runs before a tool use can block it and send the AI a message, and the AI then adjusts. Hooks live in `.claude/settings.json`.
  3. Ask the AI to turn the standing instructions into hooks for every rule that a script can check. Have it confirm the list first, then explain how to test the hooks.
  4. Keep the enforced set small: a hook is for a rule with no exceptions, and preferences stay as guidance.
  5. Put strict guardrails that are unwanted all the time into a skill that switches them on only for risky work.
- **Asset:** the source's prompt that turns standing instructions into hooks, with an example hook script: [hook guide](https://www.aihero.dev/how-to-use-claude-code-hooks-to-enforce-the-right-cli). Reference: [Claude Code hooks documentation](https://code.claude.com/docs/en/hooks).
- **Limits:** only for rules a script can check (commands, tool names, file paths); a sandbox limits where the agent acts, not what it does.
- **Requires:** Claude Code.
