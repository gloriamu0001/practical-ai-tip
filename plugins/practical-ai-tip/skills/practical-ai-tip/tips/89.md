## 89. Work in Shared Places So Context Builds Up

Work done in shared documents, folders and channels becomes context that colleagues and AI can find later. Work kept in one person's head or private notes is lost to both.

- **Use when:** working in a team, or building up context an agent should use.
- **Implementation:**
  1. Do the work in shared documents, folders and channels.
  2. Test it: could a new teammate repeat last week's work using only the shared context?
  3. Optionally, add a standing instruction to post a short update with links to a work-log channel after each substantial task.
  4. Start agent work in a shared channel or tracker. When the agent lacks context, tag in the colleague who has it.
- **Requires:** shared tools; connectors if the AI should read them; an agent that people can call in the shared tool.
