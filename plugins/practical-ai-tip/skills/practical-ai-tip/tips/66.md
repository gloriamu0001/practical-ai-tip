## 66. Treat Everything an Agent Reads as Possible Instructions

An agent cannot reliably tell instructions from content. A document, email, web page, tool result or message from another agent can carry hidden instructions that steer it.

- **Use when:** connecting an agent to email, documents, the web, connectors or other agents.
- **Implementation:**
  1. Treat all content the agent reads as untrusted, including output from tools that are themselves trusted.
  2. Give the agent's tools only the permissions the task needs, read-only where possible.
  3. Require a person's approval for high-impact actions, and for any action that changes the goal.
  4. Try unfamiliar tools and files on fake data first, in an environment where a harmful tool can do little damage.
- **Limits:** no prompt or detection product can guarantee safety; a vetted connector does not make its data safe.
