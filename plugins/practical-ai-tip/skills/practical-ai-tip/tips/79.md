## 79. Turn Repeated Work Into Skills, and Share Them

Work that repeats is worth a skill. Written instructions also travel better than finished tools: another person's agent can adapt them to a different setup.

- **Use when:** a task repeats, or a working method is worth sharing.
- **Implementation:**
  1. Write the repeated task as a skill: what it does, when to use it, and the steps. Keep each skill to one clear job.
  2. Once a skill has proved its value in use, share it with others, or bundle skills, connectors and agents into a plugin a team installs in one step (`/plugin` in Claude Code).
  3. To share a method, share the written idea or instructions, not only the finished tool. Another person's agent can build and adapt it.
  4. Prefer instructions in plain language over complex scripts where the AI can adapt to each setup, for example an installation guide written for an AI to follow.
  5. In the Claude app, store the instructions for a repeated task once in a Project's custom instructions, and paste in only the new material each time.
  6. Package a workflow so that someone other than its creator can run it: who it is for, its scope and limits, its sources, steps, review points and owner.
  7. When the agent repeats a sequence of steps by hand, ask it to write the skill it wishes it had.
- **Limits:** unused skills still add weight.
- **Requires:** an agent that supports skills.
