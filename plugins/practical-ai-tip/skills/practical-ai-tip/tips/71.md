## 71. Choose the Simplest Loop, and Hand Off One Piece at a Time

Every agent task is a loop that runs until a stop condition. Pick the simplest loop that fits, and hand over control one piece at a time: first the check, then the stop condition, then the trigger, then the whole task.

- **Use when:** deciding how much of a task to automate.
- **Implementation:**
  1. Pick the loop:
     - **Turn-based:** a prompt starts it, the AI decides when it is done. Use it when exploring.
     - **Goal-based:** it stops when a stated condition is met. Use it when "done" is clear.
     - **Time-based:** it runs on an interval. Use it for scheduled work.
     - **Proactive:** an event or schedule starts it with no one present. Use it for recurring, well-defined work.
  2. Start with one task where the user is the bottleneck. Hand off one piece, run it, watch where it stalls, and improve.
  3. Give every automated output an owner who reviews it. Do not start with a loop over a whole backlog: output that nobody reviews piles up. Get one complete loop working on simple, low-stakes work before complex work.
- **Requires:** Claude Code for goal-based and time-based loops.
