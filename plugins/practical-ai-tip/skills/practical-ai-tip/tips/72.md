## 72. Use a Fixed Workflow When the Steps Are Known

If a task can be done by fixed steps, do it that way. Use an agent, which decides its own steps and when to stop, only where the steps are unclear.

- **Use when:** designing an AI workflow, or choosing between a script and an agent.
- **Implementation:**
  1. Decide who should set the steps and when to stop.
  2. For a clearly specified task done the same way again and again, write the steps down as a fixed workflow.
  3. For a task whose steps are unclear and need improvising, use an agent.
