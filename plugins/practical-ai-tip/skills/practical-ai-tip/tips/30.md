## 30. Load Detailed Guidance Only When Needed

Keep detailed guidance in separate files and skills that load when a task needs them, instead of putting everything in the always-loaded instructions.

- **Use when:** guidance applies to only some tasks.
- **Implementation:**
  1. Move guidance for one area (tone, formatting, a client, a procedure) into its own file or skill.
  2. From the main instruction file, point to it lightly, for example: "For brand voice rules, see docs/BRAND-VOICE.md".
  3. Split long guidance into a tree of smaller files.
  4. Keep facts that every task needs in the always-loaded file, and put procedures into skills that load when called.
- **Limits:** pointers break when files move.
- **Requires:** an agent that reads files, or a tool that supports skills or knowledge files.
