## 5. Choose the First Tasks to Hand Over

Good first tasks to hand to an agent are recurring, low-risk and easy to judge, with the thinking at the start and the end and the dull work in the middle.

- **Use when:** starting to delegate work to AI, or looking for the next task to hand over.
- **Implementation:**
  1. Check candidate tasks against the five traits below; a good candidate has a few of them, not necessarily all.
  2. Ask the AI which tasks the user does most often and which are worth trying. Without memory of past conversations, describe the work and ask how the AI could automate it, starting with steps where information is copied and pasted.
  3. Start with one recurring, lower-risk task, using one real example and a clear idea of what a good result is.
  4. Keep the first run draft-only, review it, improve the instructions, and save what worked. When the result falls short, ask for specific changes, as with a colleague, rather than only accepting or rejecting it.
  5. In an organisation, widen a pilot only after the people responsible for legal, privacy, security, records and information technology have reviewed it.
- **Asset:** the five traits, from the source:
  ```
  - More than one thing goes in. Multiple files, a whole folder, or a file plus some connectors. If there's only one input, chat probably handles it fine for the most part (you should still experiment).
  - A file comes out. You need a deliverable that you can attach, present, share, or repurpose: a doc, a deck, a spreadsheet, or a CSV.
  - You'll do it again. One-offs are fine, but recurring tasks are the sweet spot. You can schedule them to run before you're even at your desk.
  - You already know what good looks like. You're familiar with the shape of the output, so you can tell in 15 seconds whether the output is right, wrong, or 70% there.
  - The middle is the boring part. The thinking lives at the start (deciding what you want) and the end (deciding if it's right). Everything in between (extract, compile, reconcile, and reformat) is what you hand off.
  ```
