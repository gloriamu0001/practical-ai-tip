## 21. Let the AI Write the Detailed Prompt for Another Tool

Current models write good, detailed prompts for other models and tools.

- **Use when:** another AI tool, such as an image generator, needs a detailed prompt.
- **Implementation:**
  1. Give the agent access to the other tool.
  2. Describe what is wanted, and let the agent write the detailed prompts.
- **Requires:** an agent with access to the other tool.
