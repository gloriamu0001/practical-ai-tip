## 45. Watch the Agent's Plan and Correct It Early

A mistake caught as one wrong step in the agent's plan costs one sentence to fix; the same mistake found in the finished work costs a redo.

- **Use when:** an agent starts a substantial task.
- **Implementation:**
  1. Watch the first minute of a run, and the plan the agent shows: what it intends to do, which files it reads and writes, which tools it uses.
  2. Correct a wrong step in one sentence; the agent adjusts without starting over.
  3. In Claude Code, press Esc the moment the agent drifts; Esc stops it and keeps everything up to that point.
  4. When the tool shows little of the agent's reasoning, build checkpoints into the brief where the agent reports interim ideas, prototypes or tests, and give feedback at each.
- **Requires:** a tool that shows the agent's plan or steps, such as Claude Cowork or Claude Code.
