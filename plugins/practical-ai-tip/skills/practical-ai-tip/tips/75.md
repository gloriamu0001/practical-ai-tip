## 75. Schedule Recurring Work

Turn a chore that repeats into a skill, then run it on a schedule, so it happens without anyone starting it.

- **Use when:** the same piece of work recurs daily or weekly.
- **Implementation:**
  1. Write the chore as a skill first. Choose work that is mechanical, can be checked, and never ends.
  2. To run it at intervals while the computer is on, use `/loop` with an interval and the skill or prompt.
  3. To run it in the cloud, even with the laptop closed, use `/schedule`. Claude Code routines can also start on an event or from a web request.
  4. Send the results of each recurring job to one place, with one thread per job. Review every result before keeping it.
  5. Let a recurring skill keep a log of earlier runs, so each run can compare with the last.
- **Asset:** an example from the source:
  ```
  /loop every morning use the Slack MCP to give me a summary of top posts I was tagged in
  ```
  ("Slack MCP" is the connector that gives the agent access to Slack.)
- **Limits:** many results need discarding[^B120]; uses the usage allowance.
- **Requires:** Claude Code; connectors for the services involved.
