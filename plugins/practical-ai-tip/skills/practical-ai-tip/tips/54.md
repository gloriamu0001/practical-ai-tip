## 54. Ask for a Log of Deviations During Long Work

Have the agent keep a running notes file that records the decisions it made and where it departed from the plan, and why, so mid-run decisions can be reviewed and reused.

- **Use when:** an agent runs a long task from a plan.
- **Implementation:**
  1. Ask the agent to keep a temporary notes file during the work: decisions the plan did not cover, changes, trade-offs, and anything the reviewer should know.
  2. When something forces a departure from the plan, the agent picks the cautious option, logs it, and continues.
  3. For each important decision, have the log state what was decided, why, the evidence used and the outcome. At the end, have the agent check the log against the session.
  4. Review the log afterwards, and use it to improve the next brief.
- **Asset:** the source's prompt:
  ```
  Keep an implementation-notes.md file. If you hit an edge case that forces you to deviate from the plan, pick the conservative option, log it under 'Deviations', and keep going.
  ```
- **Requires:** an agent that writes files.
