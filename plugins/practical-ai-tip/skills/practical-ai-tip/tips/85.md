## 85. Connect the AI to Where Information Lives

Connect the AI to the services that hold the information (chat, documents, task trackers, databases), so it can pull and post data instead of relying on copy and paste.

- **Use when:** work depends on information in other apps.
- **Implementation:**
  1. Add connectors (also called MCP servers) for the services involved.
  2. Hand the AI the raw material directly, for example a message thread, and state the goal.
  3. Turn a recurring "gather everything" task into a skill, for example one that collects the last week's messages, documents and tasks into one summary.
  4. Prefer a command-line tool where one exists; otherwise use a connector.
  5. Keep a short annotated list of key documents, with a line on what each holds.
  6. Where a service has no connector, let a browser agent work through its website, for example online forms, settings pages, registrations or cancellations.
- **Asset:** the source's connector configuration (Slack):
  ```json
  {
    "mcpServers": {
      "slack": {
        "type": "http",
        "url": "https://slack.mcp.anthropic.com/mcp"
      }
    }
  }
  ```
- **Limits:** each connected server costs context even when unused; web pages can carry instructions aimed at a browser agent.
- **Requires:** an AI tool that supports connectors; for websites, a browser tool.
