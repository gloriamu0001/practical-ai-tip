## 22. Break Work Into Thin End-to-End Slices

Split large work into small tasks that each produce a working piece from start to finish, and check each piece before starting the next.

- **Use when:** a project is too big for one session.
- **Implementation:**
  1. Split the work into thin slices. Each slice delivers one small, complete piece of the whole, not one layer done in isolation.
  2. Build one slice, run it and check it, then start the next.
