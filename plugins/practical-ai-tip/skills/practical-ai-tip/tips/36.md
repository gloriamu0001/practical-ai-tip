## 36. Keep the Context Focused: Clear Between Unrelated Tasks

Every request sends the whole conversation, so a session that still holds earlier, unrelated tasks pays for them on every turn, and a focused context gives better answers. Clear between unrelated tasks.

- **Use when:** moving from one task to an unrelated one in the same session.
- **Implementation:**
  1. Between unrelated tasks, clear the session (`/clear` in Claude Code) and write a short brief: goal, constraints, relevant material, what was ruled out.
  2. For a related next step, compact the session (`/compact`) with a hint on what to keep. A summary keeps momentum but loses detail.
  3. Beyond this, do not manage the context window aggressively: with the 1-million-token windows of most current models and automatic compaction, running out of context is rare. Clear or compact when answers get worse.
- **Asset:** a compact hint (software example):
  ```
  /compact focus on the auth refactor, drop the test debugging
  ```
- **Limits:** answer quality drops as the context grows, well before a large window is full.
- **Requires:** Claude Code, for the commands.
