## 26. Save Hard-Won Research in a File, Then Delete It

When a project depends on facts that are hard to find, save the findings in a file next to the work, so each new session does not search again.

- **Use when:** the work depends on an unfamiliar service, scattered documentation or a niche topic.
- **Implementation:**
  1. Ask the AI to write the findings into a research notes file.
  2. Point later sessions to the file.
  3. Delete the file when the project or phase ends.
- **Limits:** old research goes stale and misleads.
- **Requires:** an AI tool that reads files or accepts attachments.
