## 37. One Task per Fresh Session

When working through a list of tasks, give each task its own new session, carried by the task list and a progress file. Each session then starts with an empty context window, where answer quality is highest.

- **Use when:** working through several tasks, by hand or in an automatic loop.
- **Implementation:**
  1. Keep the task list and a short progress file outside the conversation.
  2. Start a new session for each task, with both files as input.
  3. Avoid repeating tasks inside one long session, even automatically. The context fills a little more each round.
- **Limits:** each new session spends some tokens re-reading the inputs.
- **Requires:** an agent, for automatic loops.
