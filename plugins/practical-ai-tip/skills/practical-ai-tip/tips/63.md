## 63. Ask the AI to Review How the User Works With It

Ask the AI for an honest, evidence-based review of how the user works with it, and for one specific next step to practise, then repeat the review regularly.

- **Use when:** wanting to get better at working with AI, or unsure which habit to change next.
- **Implementation:**
  1. In Claude Code, run `/insights` for a report on recent sessions: how Claude Code is used, where things go wrong, and features to try.
  2. In any assistant, ask for an assessment of how the user works with AI. Have it ask up to five questions, one at a time, about specific recent tasks, and use past conversations only when it can actually see them.
  3. Ask for the evidence behind the assessment, what already works, the main constraint, and one specific, low-risk task to try this week, with a way to tell whether it helped.
  4. Repeat the review regularly, and ask for upgrades to the workflow each time.
- **Asset:** a full assessment prompt from a source (it ends with reading suggestions for the publisher's own articles; leave those out): [assessment prompt](https://every.to/ai-level-prompt).
- **Limits:** unreliable without evidence of repeated behaviour in real work.
- **Requires:** Claude Code, for `/insights`.
