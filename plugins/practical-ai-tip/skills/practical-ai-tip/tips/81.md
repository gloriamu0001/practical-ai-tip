## 81. Seed a Skill With Examples of Good Output

Give the AI examples of the desired output, and have it extract the patterns into a skill, such as how a document is structured or the tone it uses.

- **Use when:** good examples of the desired output already exist, but the rules behind them are not written down.
- **Implementation:**
  1. Collect a few examples of the desired output.
  2. Ask the AI to extract the patterns, such as structure, tone or organisation, and write them into a skill.
  3. Run the skill, and correct the output inside the same session, so the corrections build up as before-and-after pairs in the conversation.
  4. Once the output is right, ask the AI to merge the feedback into the skill.
- **Limits:** the first version rarely works perfectly; with current models, many examples can make output less creative.
- **Requires:** an agent that supports skills.
