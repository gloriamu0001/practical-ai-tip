# All tips by topic group

89 tips. Last review of the tip bank: 2026-11-12. Ask for a tip number to see the full tip.

## A. Working with AI (7 tips)

- **1. Treat Every Session as a Capable New Starter With No Memory:** Give each session written process and context
- **2. Delegate Like Briefing a Colleague:** Brief like a colleague; leave the method to the agent
- **3. Keep Judgement and Understanding; Delegate the Legwork:** Delegate legwork; keep decisions and understanding
- **4. Use Chat for Answers, an Agent for Deliverables:** Chat for answers; an agent for deliverables
- **5. Choose the First Tasks to Hand Over:** Recurring, low-risk, easy to judge; first run draft-only
- **6. Judge AI by Current Paid Tools, and Know Where It Is Strongest:** Use current paid tools; strongest where answers can be checked
- **7. Bring Big, Ambitious Problems:** Bring big problems; test new models with open-ended tasks

## B. Clarifying before work (9 tips)

- **8. Skip a Separate Planning Mode; Align Through Conversation:** Align through conversation, write the plan to a file, build in a fresh session
- **9. Have the AI Interview the User:** "Interview me relentlessly…" with recommended answers
- **10. Have the AI Restate the Goal Before It Starts:** Ask for the goal and problem in the AI's own words before work
- **11. Prototype Several Options When Words Are Not Enough:** Several options in one HTML page for questions words cannot settle
- **12. Keep Each Alignment Session Small, and Steer It:** Split the topic; steer; stop when the plan stops changing
- **13. Write the Agreed Decisions Down Before Building:** Handoff file first, then build in a fresh session
- **14. Record Hard Decisions as They Settle:** Short decision records only for hard-to-reverse trade-offs
- **15. Use the Largest Model for Idea Work, a Smaller One for Execution:** Large model for ideas, smaller for execution
- **16. Speak Instead of Typing:** Dictate freely; correct the restatement

## C. Briefing and planning (11 tips)

- **17. Put the Whole Brief in the First Message:** Goal, constraints, acceptance criteria in the first message
- **18. Give the Richest Reference Available:** Real examples, mockups, rubrics over descriptions
- **19. Fence the Sources, and Separate Fact From Inference:** Use only named sources; separate fact, inference and gaps
- **20. For High-Stakes Documents, Extract Sourced Facts Before Writing:** Sourced facts, then open questions, then the document
- **21. Let the AI Write the Detailed Prompt for Another Tool:** Let the agent write detailed prompts for other tools
- **22. Break Work Into Thin End-to-End Slices:** End-to-end slices; check each before the next
- **23. Ask for Plans Led by the Decisions Most Likely to Change:** Changeable decisions first, concise, open questions last
- **24. Ask for the Outline Before the Deliverable:** Edit a short outline before the deliverable is built
- **25. Write Down What the AI May Do, What a Person Decides, and When It Stops:** Write what the AI may do, what a person decides, when it stops
- **26. Save Hard-Won Research in a File, Then Delete It:** Save hard-won facts; delete after the phase
- **27. State the Quality Bar, and Name the Material the AI Must Not Imitate:** Say draft or production; name the material not to imitate

## D. Instructions and context (8 tips)

- **28. Keep Always-Loaded Instructions to the Essentials:** Only what cannot be discovered and every task needs
- **29. Put Each Instruction at the Level Where It Applies:** Personal, project, organisation
- **30. Load Detailed Guidance Only When Needed:** Separate files and skills, pointed to lightly
- **31. Give Judgement, Not Rigid Rules:** Describe the outcome, not a rigid rule
- **32. Keep Work in Folders the AI Reads and Writes:** Keep work in folders the agent reads and writes
- **33. Audit the AI Setup Regularly:** Measure, remove unused, measure again
- **34. Revisit Saved Instructions After a Model Change:** Review skills and memory written for the old model
- **35. When the AI Errs, Fix the Source of the Error:** Fix the instruction, skill or routine, not just the output

## E. Managing the context window (4 tips)

- **36. Keep the Context Focused: Clear Between Unrelated Tasks:** Clear between unrelated tasks; compact with a hint
- **37. One Task per Fresh Session:** One task per session, with task list and progress file
- **38. Rewind Instead of Correcting:** Go back and re-prompt instead of correcting
- **39. Keep Side Work Out of the Main Conversation:** `/btw`, `/branch`; helper agents only for parallel, noisy or review work

## F. Checking quality (17 tips)

- **40. Give the AI a Way to Check Its Own Work:** Give the AI a check it must pass
- **41. Use the Cheapest Check That Works:** Fix gaps, rule checks, then AI judges
- **42. Use Pass-or-Fail Checks, Not Rating Scales:** Binary checks, not rating scales
- **43. Let a Fresh Checker Judge the Work:** A checker that did not see the work, with a scope, validated against a person
- **44. Have a Second Session Watch a Long Run:** Second fresh session checks the brief against the run: execution drift often, direction drift occasionally
- **45. Watch the Agent's Plan and Correct It Early:** Watch the first minute; correct a wrong step in one sentence
- **46. Require Proof With Every Output:** Require evidence with every output
- **47. Ask the AI to Argue the Opposite:** Ask for the opposite case; watch for sycophancy
- **48. Ask the AI for a Critique, Not a Rewrite:** Ask for a prioritised critique, not a rewrite
- **49. Review Where the Stakes Are High, and Get Quizzed:** Read where stakes are high; pass a quiz
- **50. Put a Short Human-Chosen Opener First:** Short human-chosen opener first
- **51. Verify an Incoming Claim Before Acting on It:** Reproduce, check duplicates, check past rejections
- **52. Let the AI Recommend; Apply Changes Only After Approval:** The AI recommends; a person approves
- **53. Work on a Copy of Important Files, Then Audit the Changes:** Duplicate first; audit formulas, citations and changed cells
- **54. Ask for a Log of Deviations During Long Work:** Notes file of decisions and departures from the plan
- **55. Read Real Outputs Before Writing Checks or Criteria:** Read real outputs before writing checks or criteria
- **56. Build a Small Test Set Before Changing a Workflow:** About 10 tasks; change one thing at a time

## G. Output, effort and learning (7 tips)

- **57. Ask for Visual Output: HTML Pages, Diagrams, Slides:** Ask for the answer as an HTML page
- **58. Ask for Controlled Plain Language:** "80% of the way to ASD-STE100"
- **59. Split Long Documents When the Answer Grows With Them:** Split into pieces, answer each, then combine
- **60. Start With a Read-Only Look at a Data File:** Inspect, audit data quality, then analyse
- **61. Pick the Effort Level by the Job:** Low to sketch, medium for regular work, high to check, max for hand-offs
- **62. Use AI to Learn, Not Only to Produce:** Explanatory style, explain-back, quizzes
- **63. Ask the AI to Review How the User Works With It:** Ask for an evidence-based review and one next step to practise

## H. Control and safety (6 tips)

- **64. Enforce Must-Hold Rules With Permissions or Hooks:** Permissions and hooks, not prose
- **65. Reduce Permission Interruptions Safely:** Auto mode, allow lists, sandbox
- **66. Treat Everything an Agent Reads as Possible Instructions:** Anything the agent reads can carry instructions
- **67. Never Combine Private Data, Untrusted Content and a Way to Send Data Out:** Never private data + untrusted content + a way out in one agent
- **68. Vet Tools, Skills and Templates Before Installing Them:** Known sources; check the origin before installing
- **69. Supervise First, Then Run Unattended With a Cap and Isolation:** Supervise first; cap rounds; isolate

## J. Knowledge and memory (3 tips)

- **87. Build a Knowledge Base the AI Writes and Maintains:** raw folder → AI-maintained wiki → answers filed back
- **88. Prefer Memory That Can Be Seen and Edited:** Automatic memory plus files the user owns
- **89. Work in Shared Places So Context Builds Up:** Work where colleagues and AI can find it

## Terms the tips use without definition

- **Agent:** an AI tool that acts on its own: it reads and writes files, runs commands and uses connected services. Examples: Claude Code, Claude Cowork.
- **Context window:** everything the model can see in one conversation. It has a fixed size, counted in tokens (about ¾ of a word each).
- **Session:** one conversation with its own context window.
- **Skill:** a saved set of instructions that an agent loads only when a task needs it.
- **Prompt:** the instruction typed to the AI.
