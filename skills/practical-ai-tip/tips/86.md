## 86. Steer Running Work From Any Device

Agent work does not have to stay tied to one computer. Start or steer it from a phone or the web.

- **Use when:** away from the computer while work is running, or when quick tasks come up on the move.
- **Implementation:**
  1. Control a session on the computer from a phone or the web with `/remote-control`.
  2. To make every session controllable this way, run `/config` and turn on "Enable Remote Control for all sessions".
  3. Continue a cloud session on the computer with `/teleport`.
  4. From the Claude mobile app, use Dispatch to send a task to the Claude desktop app on the computer, such as catching up on email and messages or managing files.
- **Requires:** Claude Code or the Claude desktop app, plus the Claude mobile or web app; for remote control, a paid Claude plan, not a developer key.
