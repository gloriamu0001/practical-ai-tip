## 70. Run Several Sessions in Parallel

Independent tasks do not need to wait for each other. Run several sessions at once, each on its own task, and track them from one place.

- **Use when:** there are several independent tasks, or one session is waiting on the AI.
- **Implementation:**
  1. Give each session one task and a clear name.
  2. Keep sessions from colliding: give each its own copy of the work where they would edit the same files.
  3. Switch to another session while one is working. During planning, answer in one session while the other thinks.
  4. Track all sessions in one list grouped by status, for example `claude agents` in Claude Code.
  5. Get notified when a session finishes or needs input, and read its recap on return. A catch-up prompt a source uses:
     ```
     catch me up on everything since my last message, and if there are any action items for me give me enough context (exec summary) to make a call
     ```
  6. Start every task whose prerequisites are finished at the same time, instead of one by one.
- **Limits:** more review work; two or three planning sessions at once is a practical maximum; collisions show only when pieces are combined.
- **Requires:** a tool that allows several sessions; Claude Code for the session list and recaps.
