## 49. Review Where the Stakes Are High, and Get Quizzed

Reading everything an agent produces does not scale. Read closely where errors would be costly, and make sure the result is understood.

- **Use when:** an agent has finished substantial work.
- **Implementation:**
  1. Ask the AI for a review plan: the scenarios to check, the edge cases, and the criteria for "done". Check the work against it.
  2. Read closely the parts that are critical or must be exactly right.
  3. Ask for a readable report on what changed, with a quiz at the end, and accept the work only after passing.
  4. Turn each problem found into a new task, and repeat.
  5. Before handing AI-produced work to someone else, check it personally, read any summary the AI wrote, and say how the work was checked.
  6. Check the full package, not only the summary: facts, calculations, quotations, citations and recommendations.
- **Asset:** the source's report-and-quiz prompt:
  ```
  Give me an HTML report on the changes to read and understand with context, intuition, and what was done — and a quiz at the bottom on the changes that I must pass.
  ```
- **Limits:** tiring at high volume; deciding what is critical stays a human judgement; a confident explanation is not evidence.
