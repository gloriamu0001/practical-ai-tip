## 44. Have a Second Session Watch a Long Run

Long sessions drift as errors build up. A second session with a fresh context can compare the original brief with what the working session is doing, and give feedback to correct course.

- **Use when:** an agent works on a task for a long time, especially without supervision.
- **Implementation:**
  1. Append the initial instructions and every follow-up prompt to one shared file.
  2. Start a second session with a fresh context.
  3. Periodically, have the second session read the brief and the working session's recent turns, and give feedback if something is off.
  4. Check often for execution drift: is the agent doing the task right? Examples are ignoring an error, reporting a bad number, or departing from the brief.
  5. Check occasionally for direction drift: is the agent doing the right task? This happens when it misreads the intent and spends hours building the wrong thing.
- **Limits:** a vague instruction can still make the agent add rules and approval steps that slow the work.
- **Requires:** a tool that allows two sessions at once, and a shared file both can read.
