## 60. Start With a Read-Only Look at a Data File

Begin work on a data file with a pass that changes nothing: have the AI explain what is in the file, then audit its data quality, and only then analyse.

- **Use when:** handing a spreadsheet or data file to the AI for analysis.
- **Implementation:**
  1. Ask the AI to inspect every part of the file, summarise what each holds, identify the authoritative parts, and not edit anything yet.
  2. Ask it to audit the data for issues that could distort the result, ranked by impact, and to show the records that need a person's review.
  3. Then run the analysis.
  4. Check the numbers the analysis uses against trusted reports, dashboards or earlier analysis, so they are consistent.
  5. Then ask for a plain-language summary that includes the data issues that still need review.
- **Requires:** an AI that can read the file.
