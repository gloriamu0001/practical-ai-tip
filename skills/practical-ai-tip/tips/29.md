## 29. Put Each Instruction at the Level Where It Applies

Where an instruction lives decides who it applies to. Keep personal preferences personal, shared rules shared, and organisation policy where no one can override it.

- **Use when:** adding a rule or preference to an AI tool's standing instructions.
- **Implementation:**
  1. Put personal preferences that apply to all work in the personal instruction file. In Claude Code this is `~/.claude/CLAUDE.md`, read at the start of every session; in ChatGPT, the personalisation feature.
  2. Use the personal file for working-style preferences, for example how direct to be, when to push back, and saying when unsure instead of guessing.
  3. Put rules for everyone on one project in that project's shared instruction file, or in the project's instructions in a chat tool (a Project in ChatGPT or Claude): the tone, the facts the AI may use, what it must never invent, and what stays in draft.
  4. Put organisation policy in managed settings, which no personal file can override.
- **Asset:** two lines from a source's personal file:
  ```
  - Be direct and push back when you disagree; if my approach has problems, say so.
  - When unsure about something, say you're unsure rather than guessing confidently.
  ```
  An official source's project instructions, written for a fictional florist, as a labelled example to adapt:
  ```
  This Project supports marketing for Harbor Bloom, a fictional neighbourhood florist in Cork, Ireland. Use a warm, practical tone. Use only approved business facts and cited public sources. Keep research, draft customer messages and owner briefings together. Do not invent prices, opening hours, delivery areas, contact details, availability or partnerships. Flag missing facts and distinguish evidence from recommendations. Keep all external communications in draft for review.
  ```
- **Limits:** everything in the file loads into every session it applies to.
- **Requires:** an AI tool with standing instructions; for managed settings, Claude Code in an organisation.
