## 46. Require Proof With Every Output

Put an evidence requirement into the request itself, so each result arrives with its own proof and checking it is fast.

- **Use when:** delegating work that will be reviewed, especially automated or repeated work, or asking others to approve finished work.
- **Implementation:**
  1. In the request, require the agent to run its check and attach the evidence: a reproduction, a before-and-after comparison, a table of cases and results, or a screen recording or screenshots of the result working end to end.
  2. Before accepting a result, ask the agent to prove that it works.
  3. Ask for a before and an after, not just a statement that a check passed.
  4. Check the actual result, not the agent's report of it.
- **Limits:** a recording shows behaviour, not underlying quality; checking with computer use (a tool that lets the AI operate the screen) can be expensive.
- **Requires:** for recordings, a browser tool or computer use.
