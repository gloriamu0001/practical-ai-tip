## 55. Read Real Outputs Before Writing Checks or Criteria

Before building any check for an AI workflow, read its real outputs and note what goes wrong in each. The criteria come from the outputs.

- **Use when:** improving an AI workflow that runs repeatedly, or deciding what to check.
- **Implementation:**
  1. Collect real outputs, as varied as possible.
  2. Ask the agent to build a simple review page: each output in its familiar format, the context a reviewer needs on the same screen, and less important details in sections that expand.
  3. Write free notes on each one, before writing any rubric (a written list of grading criteria). Focus on the first failure in each, because earlier errors cause later ones.
  4. Stop when new outputs no longer reveal new failures.
  5. Repeat after significant changes, such as new instructions or a switch of model.
- **Limits:** about 30 minutes per 20–50 outputs (fuller guidance: at least 100); AI misses outputs that look right but fall short.
- **Requires:** an agent that can build a review page.
