## 1. Treat Every Session as a Capable New Starter With No Memory

A new session knows nothing about the work, the decisions made or the usual way of doing things, so give it written process and context every time.

- **Use when:** setting up any repeated or long-running work with AI.
- **Implementation:**
  1. Write the process for recurring work as steps an agent can follow.
  2. Write down knowledge that otherwise lives only in people's heads: domain terms, conventions, known pitfalls. Put it in files the agent reads: the instruction file, skills, docs.
  3. When an output is rejected because the agent lacked some knowledge, add that knowledge to those files.
  4. Write the project instruction file like a new teammate's first-day document, for example with a glossary of the project's terms and a reading order. Keep it short, because it loads into every session.
- **Limits:** needs upkeep; stale documents mislead.
- **Requires:** an agent that reads files, for steps 2–3.
