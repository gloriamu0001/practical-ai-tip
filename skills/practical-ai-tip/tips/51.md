## 51. Verify an Incoming Claim Before Acting on It

Before working on a request or report from someone else, check that it holds, that it is not already done, and that it was not rejected before.

- **Use when:** handling complaints, reports or requests from other people.
- **Implementation:**
  1. **Confirm it:** follow the stated steps and see whether the problem happens as described.
  2. **Already done?** Search by concept, not by the requester's wording.
  3. **Rejected before?** Keep one short file per rejected idea, with the reason. Match new requests by concept and show the old reason instead of arguing again.
  4. Report one of three results: confirmed, failed to reproduce, or not enough detail to try. Only a confirmed request moves on.
  5. Sort each confirmed request: small and clear, the agent does it; large, the agent drafts a plan for a person to review; ambiguous, ask a person; otherwise, park it. Give the agent the documents that state the goals, so it can judge fit.
- **Limits:** does not find the root cause.
- **Requires:** an agent with access to the material the request is about.
