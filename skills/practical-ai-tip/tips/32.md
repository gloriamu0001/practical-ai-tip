## 32. Keep Work in Folders the AI Reads and Writes

Work kept in folders that the agent reads and writes lets it find earlier work, notes and analysis on its own.

- **Use when:** setting up the files an agent works with.
- **Implementation:**
  1. Keep the work in folders that the agent can read and write.
  2. Let the agent find earlier work in the folders itself instead of pasting material in.
- **Requires:** an agent that can read and write files, such as Claude Code or Cowork.
- **Reference:** [^EY][^AN-coworkproj]
