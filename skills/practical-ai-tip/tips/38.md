## 38. Rewind Instead of Correcting

When the agent goes down a wrong path, go back to before the mistake and prompt again with what was learned. A correction typed afterwards keeps the failed attempt in the context.

- **Use when:** an attempt failed and the cause is understood.
- **Implementation:**
  1. Run `/rewind` (or press Esc twice) in Claude Code, and pick the message before the mistake.
  2. Prompt again with the lesson, for example "use approach C, not A or B".
  3. Optionally ask for a short note first ("summarize from here"), so the lesson carries over.
  4. After two failed corrections, clear the session and prompt again instead of correcting a third time.
- **Requires:** Claude Code.
