## 67. Never Combine Private Data, Untrusted Content and a Way to Send Data Out

An agent that can read private data, read content an outsider controls, and send information out can be tricked into leaking the data. Do not give one agent all three.

- **Use when:** choosing which tools and connectors an agent gets.
- **Implementation:**
  1. For each agent, check for the three capabilities:
     - **private data:** for example email, documents, accounts
     - **untrusted content:** any text or image an outsider could control, such as web pages or incoming email
     - **a way out:** anything that can send data out, such as a web request, loading an image, or a link the user clicks
  2. If one agent has all three, change the setup so it does not.
- **Limits:** no known way makes the combination fully safe; vendors cannot protect tool combinations the user put together.
