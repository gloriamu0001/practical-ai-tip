## 82. Write a Skill's Description as When to Use It

The AI reads each skill's description to decide whether the skill fits a request. Write the description as a trigger condition with the phrases a user would say, not as a summary.

- **Use when:** writing or fixing a skill that runs too rarely or at the wrong times.
- **Implementation:**
  1. State when the skill should be used.
  2. Include the phrases a user would say when the skill is needed.
- **Asset:** the source's examples (software):
  ```
  Bad: `description: A comprehensive tool for monitoring pull request status across the development lifecycle.`

  Good: `description: Monitors a PR until it merges. Trigger on 'babysit', 'watch CI', 'make sure this lands'.`
  ```
  (PR: a proposed code change. CI: the automatic checks that run on it.)
- **Requires:** an agent that supports skills.
