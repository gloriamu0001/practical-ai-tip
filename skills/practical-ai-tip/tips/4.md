## 4. Use Chat for Answers, an Agent for Deliverables

Chat suits work whose output is a thought in the user's head; an agent that works on files and apps suits work whose output is something handed to someone else.

- **Use when:** deciding where to do a task.
- **Implementation:**
  1. Use chat when the need fits in a few exchanges: a question, an explanation, a brainstorm, a quick check.
  2. Use an agent when the need is a deliverable (a file, a deck, a spreadsheet), has several steps, or touches more than one file, file type or app. Ask for the finished file, not for notes to turn into the file by hand.
  3. For non-technical work with an agent, put the files in one folder, and say the agent may write scripts and make HTML pages.
- **Requires:** an agent that works on files, such as Claude Cowork or Claude Code.
