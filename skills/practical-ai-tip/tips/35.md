## 35. When the AI Errs, Fix the Source of the Error

Correcting a mistake in chat fixes one output. Fixing the instruction, skill or routine that produced it fixes every future run.

- **Use when:** the AI makes a mistake that could recur.
- **Implementation:**
  1. Do not just say "do it this way". Ask the AI to write the lesson where it applies: a skill for task-specific lessons, and the always-loaded instruction file (CLAUDE.md in Claude Code) only for lessons every task needs.
  2. When the same kind of problem keeps appearing, ask the AI to build an automatic check or routine that handles the whole class of problem.
  3. When a scheduled routine produces a bad result, ask the AI to tune the routine itself, and judge it over several days, not on one run.
  4. Periodically, have the AI review recent sessions for recurring corrections, such as repeated requests for something that was missed, or "still wrong", and turn the verified ones into rules, skills or checks. Write the reason next to each correction, where the agent can read it, and have a person approve each proposed change to a skill.
  5. Match the symptom to the fix: if the AI built something different, or relearns a fact every session, information is missing; if it said "done" but was not, a check is missing; if it did something forbidden, the rule needs enforcing.
  6. Keep a list of known pitfalls in each skill, adding one line each time the AI trips on something.
  7. Have agents that run repeatedly report their own misses and lessons once a week, so the mistakes do not repeat.
- **Asset:** the source's closing line after a correction:
  ```
  Update your CLAUDE.md so you don't make that mistake again.
  ```
- **Limits:** the always-loaded file grows with each lesson; tuning a routine can take a few days.
- **Requires:** an agent with instruction files or skills (Claude Code, Cowork).
