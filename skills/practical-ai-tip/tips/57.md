## 57. Ask for Visual Output: HTML Pages, Diagrams, Slides

Vision is the brain's highest-bandwidth input, so visual answers are easier to take in than text. Ask for answers as an HTML page, a diagram or slides, instead of plain text.

- **Use when:** an answer is long, complex or hard to follow.
- **Implementation:**
  1. Add the line below to the end of the request, then open the file in a browser.
     ```
     structure your response as HTML
     ```
  2. For simpler cases, ask for a diagram or a slide show instead.
  3. For hard topics, ask for a custom explainer page or video. A line a source uses:
     ```
     explain like I'm someone who knows nothing about this topic, using a HTML artifact with big pictures and few words
     ```
- **Limits:** visual output is harder for the AI to check.
- **Requires:** an AI tool that can produce files.
